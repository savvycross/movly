# Movly

Free motion graphics, made in your browser. Describe what you want (or pick one
of 13 templates), customize text, colors, font and logo, preview it, and download
MP4, WebM or GIF. No account, no server, no watermark unless you want one, $0.

```bash
npm install
npm run dev
```

Live at https://movly-gamma.vercel.app/ (Vercel deploys every push to `main`). See [CLAUDE.md](CLAUDE.md)
for project details and the $0 rule.
